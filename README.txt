SV AQUA FARM WEBSITE

How to use:
1. Extract/unzip this folder.
2. Open the file named index.html in Chrome, Edge, or Firefox.
3. The website works locally without installing anything.
4. To publish it online, upload the entire folder to a hosting service such as GitHub Pages, Netlify, or Vercel.
5. Your phone number, WhatsApp button, and Instagram link are already included.

Files:
- index.html  = website content
- style.css   = design and responsive layout
- images/     = shrimp photos supplied for the website

To edit:
- Open index.html in Notepad or VS Code.
- Change text, varieties, or links.
- Replace images inside the images folder if needed.
